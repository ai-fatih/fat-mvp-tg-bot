Пояснения к структуре — зачем и как использовать

bot/ — всё, что связано со “внутренней” логикой бота: команды, обработчики, основной запуск. Это центр логики.

services/ — слой, который взаимодействует с внешними системами: БД, API, внешними сервисами. Это позволяет не мешать “чистой бизнес-логике” и легко переиспользовать/тестировать. Такой подход хорошо соответствует рекомендациям для Node.js-проектов: разделять слои — веб-слой, сервисный и data-access.

+1

utils/ — вспомогательные функции: хелперы, форматирование, логика общего назначения. Это предотвращает дублирование кода и упрощает сопровождение. 
CodingCops
+1

config/ — все настройки, константы, переменные окружения вынесены отдельно. Это важно, чтобы не “разбросать” конфиги по всему коду, и легко менять настройки (например, токены, режимы, параметры). 
Habr
+1

data/ — если у тебя есть статичные JSON, шаблоны, локальные данные или seed-данные — удобно держать их отдельно.

tests/ — даже если сейчас нет тестов — хорошо сразу завести папку для них. Позже можно покрыть utils, services, ключевую логику. Это повышает надёжность.

index.js в корне src/ — точка входа: оттуда импортируются нужные модули, запускается бот, выполняются инициализация, конфиг, зависимости.


КОНФИГ
src/index.js — точка входа приложения.
src/bot/index.js — инициализация бота, регистрация хендлеров.
src/bot/bot.js — создаёт экземпляр бота, принимает botConfig.
src/config/ — глобальные параметры и константы.
.env — содержит TELEGRAM_BOT_TOKEN и другие необходимые переменные.


services/
├── firebase.js              // инициализация Firebase
├── firebaseService/
│   ├── index.js             // основной экспорт
│   ├── FirebaseService.js   // фасад, объединяет сервисы
│   ├── UserService.js       // работа с пользователями
│   └── MessageService.js    // работа с сообщениями


UTILS
/utils/index.js
├── экспортирует всё из:
│   ├── /state
│   │   ├── chatState.js          <- Map состояния чатов
│   │   └── stateHelpers.js      <- функции get/set/reset service messages
│   ├── /helpers
│   │   ├── timer.js             <- wait, waitRandom, botTyping
│   │   ├── logger.js            <- debug, warn, error, cleanup
│   │   ├── arrayUtils.js        <- фильтры и сортировки (пока не используется)
│   │   └── textUtils.js         <- нормализация текста (пока не используется)
│   └── /telegram
│       ├── safeSend.js          <- safeSend, safeEdit (использует botTyping + logger)
│       ├── clearServiceMessages.js <- чистка service messages (использует stateHelpers + logger)
│       ├── chatUtils.js         <- updateQuestionsList (использует safeSend, safeEdit, clearServiceMessages, keyboards, fmt/headers)
│       ├── formatMessage.js     <- fmt, headers
│       └── keyboards.js         <- функции генерации inline клавиатур
